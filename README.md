## About Me

Full-stack developer with a backend engineer's mindset. I care about the parts of software users never see but always feel: **API design, data modeling, and system reliability.**

- 🔭 Currently building production web apps with **Laravel, Next.js, and Go**
- 🏗️ Strongest at **REST API design, database architecture, and business logic** that survives scale
- 📱 Ship cross-platform mobile apps with **Flutter** when the product needs it
- 🌱 Deepening my knowledge in **distributed systems and Go concurrency patterns**
- 💬 Ask me about **Laravel, Node.js, PostgreSQL, or API architecture**
